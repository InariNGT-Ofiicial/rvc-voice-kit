# 判据手册

换声做完了，怎么判断「成不成」？这份手册记录每个指标**能证明什么、不能证明什么**，
以及本机踩过的三次「指标误导结论」。

核心原则：**客观指标只能排除明显坏掉的输出，最终仲裁永远是耳朵。**

---

## 1. Δr（音色位移）

### 定义

```
Δr = r(输出, 目标参考集) − r(源, 目标参考集)
```

`r` 是输出的**长时平均频谱（LTAS）**与目标角色参考集平均频谱的相关系数。
Δr > 0 表示朝目标移动，Δr < 0 表示反而远离。

### 它能证明

「音色方向对不对」——而且是**相对量**，比绝对值稳健。
同一段干声、同一参考集、只换模型时，Δr 的排序是可信的。

### 它不能证明

**「像不像」**。Δr 只是位移，位移 0.2 不代表像，位移 0.04 不代表不像。

**Δr 的上限被录音信道锁死。** 本机实测：同一游戏、同一条录音链采下来的素材，
源本身对目标参考集的 r 就已经到 **.9629**（参考集留一法自测上限 .9863）。
只剩 0.02 的空间，Δr≈0 是**必然**，不是失败。

> ★ 所以：**Δr 只能在同一信道内比较。** 跨信道（TTS vs 真人录音）比 Δr 没有意义，
> 结论不能互相搬运。每次对拍必须写明参考集自测上限。

### 本机基准数

| 场景 | r_src | r_out | Δr |
|---|---|---|---|
| 唱歌干声（泠鸢原唱）→ 芳乃 | .9512 | .9920 | **+.0409** |
| 日语台词（TTS 通道）→ 芳乃 | .8655 | .9567 | +.0912 |
| 日语台词（真人通道）→ 芳乃 | .9629 | ≈.96 | ≈0（信道已封顶） |
| 中文台词（CosyVoice 源）→ 芳乃 | .7564 | .9705 | +.2141 |

中文那行 +.21 看起来最漂亮，其实是**起点最低**（.756），不是换得最好。

## 2. 可懂度：三层 CER

ASR 回读原文，与台词逐字比对。中文必须分三层算，否则会把「同音字」误判成「掉字」。

| 层 | 比什么 | 判什么 |
|---|---|---|
| **汉字 CER** | 汉字序列编辑距离 | 有没有掉字/多字 |
| **拼音 CER** | 带声调拼音序列（`真子` vs `贞子` 算 0 错） | 音素是否走形 |
| **声调 CER** | 只比调号（1/2/3/4） | 声调有没有被抹平 |

配 `ref = 源音频` 与 `ref = 目标文本` 两组参考：前者判「换声有没有伤到」，后者判「能不能听懂」。

### 本机基准

| 通道 | 源 CER | 换声后 CER |
|---|---|---|
| 日语台词（4 句） | .0375 | .0375 |
| 中文台词（6 句，拼音层） | .010 | .017 / .000 |
| 中文台词（6 句，声调层） | .000 | **.000** |

**换声前后掉字量级不变** —— 这是跨语言迁移成立的最硬证据。

### 注意

- 最差单条（.059，「三遍了」→「三遍啊」）在**源音频上就已经存在**。判 CER 必须对照源的 CER，
  否则会把 TTS 的锅算到换声头上。
- whisper 的汉字输出会有同音替换（真子→贞子），所以**先看拼音层**再看汉字层。

## 3. 声调保真：tone_r 与半音 RMSE

### 定义

取 f0 曲线 → 转半音（相对 55 Hz）→ 去掉清音帧 → 与源的曲线**线性对齐** → 算相关与 RMSE。

- `tone_r`：1.0 = 声调轮廓完全保留；< 0.9 开始可疑；< 0.7 基本等于换了调型
- `tone_rmse`：> 2 半音基本等于换了调型

### ★★ 最关键的一条认知

> **声调保住靠的是 `pitch 0` 这个工程约定，不是模型懂汉语。**

RVC 在 `--pitch 0` 时，f0 直接由源音频驱动，声调是**被搬运**过去的，模型只负责音色。
推论：启用 pitch shift（变调）时，只能保住轮廓、**丢掉音区**——中文唱歌必须单独验证。

### 三个测量陷阱（都真踩过）

1. **`pyin` 会八度跳变。** 换声输出上 `pyin` 的半音 std 从 2.94 跳到 6.92，
   算出 r=.44 的假警报，而同一批的声调 CER = 0。
   ⇒ 用**换声器自身的 `rmvpe`** 测，同源同口径。
2. **DTW 在短句上会拉错曲线。** 1.2 s 浊音的句子 DTW 给 r=.64；
   而时长比只差 1%，根本不需要弯曲。
   ⇒ 时长比差 ≤1.2% 时用**线性对齐**，不要 DTW。
3. **两个判据打架时，先怀疑测量工具。** 声调 CER=0 与轮廓 r=.44 不可能同时为真，
   一定是其中一个的测量方法错了——三次里三次都是工具错。

## 4. 其他指标

| 指标 | 阈值 | 用途 |
|---|---|---|
| `f0_median_diff_hz` | \|Δ\| < 5 Hz | 确认没有整体移调 |
| `peak` | < 0.95 | 削波检查；RVC 输出通常 0.68–0.87 |
| `exact_zero_ratio` | ≈ 0 | 「精确归零」比例。DDSP 有 1.4%，需要补气口；**RVC 恒为 0** |
| `dur_ratio` | 0.98–1.02 | 时值保真；台词换声不该改语速 |
| `conv_gain_pct` | — | 换声对弱信号的增益。**不恒定**（片段间 1.5–3.9 dB），不能整文件套一个增益 |

### 已剔除的指标

**MFCC 距离**。它分不清「像源」还是「像目标」——两个方向都可能让距离变大。
只有在同一系统内部横向比较时才有意义，不适合作为验收判据。

---

## 5. 参考集自测上限

每次对拍都要算「参考集留一法」：拿参考集里每一条去和其余条的平均频谱比，
得到自测上限。本机芳乃参考集：**r = 0.9863**。

意义：你的输出 r 再高也高不过这个数；如果输出 r 接近上限，
说明**测量已经到顶了**，再优化指标没有意义，改去听。

---

## 6. 判定流程（推荐顺序）

```
1. 削波与电平   peak < 0.95？输出 rms 与源差多少？（差 > 6 dB 先查增益）
2. 时长         dur_ratio 是否在 0.98–1.02？
3. 可懂度       CER 是否与源持平？（不持平 = 掉字，优先修这个）
4. 音色方向     Δr > 0？（只在同信道内比）
5. 声调（中文） tone_r > 0.95？tone_rmse < 1 半音？
6. 听           前五项都过，再听自然度与情感
```

反过来做（先听）会陷入「这段有杂音到底是模型问题还是输入电平问题」的死循环。
