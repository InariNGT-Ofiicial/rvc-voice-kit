# RVC 2.3 CLI 化踩坑清单

全部条目都在本机真机验证过（RVC 2.3.260718 / commit `81eed5e` / Python 3.12 / Windows）。
分四组：**读源码能看出来的**、**纯 CLI 化才会撞上的**、**台词实验的**、**中文特有的**。

用法：遇到报错先在这里搜关键词，比读源码快。

---

## A. 读源码能看出来（但每一条都会白跑一轮）

| # | 坑 | 事实 | 对策 |
|---|---|---|---|
| 1 | 目录已重构 | 2.3 是 `train/`、`train/dataset/`、`infer/cli.py`；老教程的 `infer/modules/train/...` 全部 404 | 版本锁死，路径常量集中在一处 |
| 1b | `extract_f0` 第一位不是路径 | 必须以 `cpu`/`cuda` 开头：`cuda <n_part> <i_part> <i_gpu> <exp_dir> <is_half>` 或 `cpu <exp_dir> <n_p> <method>` | 照老教程写「`extract_f0.py <exp> <n_p> rmvpe`」必崩 |
| 1c | 依赖里已无 fairseq | 改用 `transformers>=4.49,<4.50` 加载 HuBERT（`assets/hubert_base/` 三件） | 源码直装可行，不必用整合包 |
| 2 | 并行参数是反的 | `preprocess.py` 第 5 位 `True` = **不并行** | 固定传 `False` |
| 3 | `filelist.txt` 没有 CLI 生成器 | 官方只给了 WebUI 里的 Python 逻辑；缺了 `train.py` 直接读不到数据 | 自己造，四路径齐备才写入（见 `scripts/train/p1_run.py:step_list`） |
| 4 | `-e` 不是路径 | 会被 `os.path.join("./logs", name)` 二次拼接 | 只传名字，且实验名全局唯一 |
| 5 | index 命名 | `trained_` 是中间产物，`added_` 才能推理；`cli.py` 会尝试把 `trained` 替换成 `added`，替换失败就报 FileNotFound | 只认 `added_*`，`--index` 给绝对路径 |
| 6 | 不给 index 直接崩 | `index_rate > 0` 且找不到 index ⇒ `FileNotFoundError`（不像 DDSP 可以不给） | 传 index，或显式 `--index-rate 0` |
| 7 | 大 pth 不能推理 | `logs/<exp>/G_*.pth` 含优化器状态 | `-sw 1` 让训练自己导出小模型 |
| 8 | ★ 安全 | 2.3 的 checkpoint 提取界面对同目录 `train.log` 末字段执行 `eval()`（上游 issue #2866，2026-10 仍存在） | **永不调用该接口**；不把第三方模型包丢进 `assets/weights` |
| 9 | 电平被改过 | `preprocess.py` 做混合归一化 `x/max*(0.9*0.75) + 0.25*x` ⇒ 峰值 ≈ 0.675 | 换声输出电平与 DDSP 不同，下游增益判据要**重新标定** |

补：多说话人模型的默认 speaker id 是**最小已声明 id**（不一定是 0）；`--protect` 上限 0.5。

## B. 纯 CLI 化才会撞上（WebUI 用户一辈子碰不到）

WebUI 的「一键训练」不是 UI 糖，它承担了六项隐含职责。少了任何一项，症状都很像「模型不行」。

| # | 坑 | 现象 | 根因 / 对策 |
|---|---|---|---|
| 10 | 必须用 `-m` 包方式调用 | `python train/preprocess.py` → `ModuleNotFoundError: No module named 'infer'`；把 repo 根塞进 `PYTHONPATH` 后又变成 `ImportError: cannot import name 'utils' from partially initialized module 'train'` | `sys.path[0]` 是**脚本所在目录**，`import train` 命中了 `train/train.py` 自身。一律 `python -m train.preprocess` / `-m infer.cli` |
| 11 | `logs/<exp>/` 必须预先存在 | `preprocess.py` 一开始就 `open("logs/<exp>/preprocess.log","a")` → `FileNotFoundError` | 它不会自建，训练前 `mkdir` |
| 12 | `logs/<exp>/config.json` 必须自己生成 | `train.py` 的 `get_hparams()` 直接读它 | 从 `configs/v2/48k.json` **原样复制**（`spk_embed_dim` 保持 109，只去掉 `speaker_info`） |
| 13 | filelist 必须绝对路径 | `FileNotFoundError: '0_gt_wavs/0_2.wav'` | `data_utils._filter()` 直接 `os.path.getsize()`，相对路径按 cwd 解析 |
| 14 | ★★ filelist 必须注入静音样本 | 训练照跑，但模型**在静音/气口处喷噪** | WebUI 给每个说话人追加 2 条 `logs/mute/*`；下 `mute.zip`（305 KB）并追加两行 |
| 15 | `ffmpeg` 必须在子进程 PATH | `WinError 2 系统找不到指定的文件`，切片「成功 0 / 失败 45」 | `infer/audio.py` 硬编码 `run(cmd=["ffmpeg"])`，不做路径探测 ⇒ 前置进子进程 PATH |
| 16 | `preprocess.py` 吞异常 | 全部切片失败，**退出码仍是 0** | 只能数产物（`1_16k_wavs/*.wav`）判断成败 |
| 17 | `assets/weights/` 必须存在 | `RuntimeError: Parent directory assets/weights does not exist`，**异常被吞，训练照常继续，只是小模型永远导不出来** | 训练前建目录；已训练的用 `train.process_ckpt.savee()` 手动补提（`hps` 里没有 `if_f0`/`version`，要单独传） |

> 这八条合起来说明：把 RVC 训练 CLI 化，实质是**把这六项隐含职责逐条补回来**。
> 这也是为什么不建议「写个 bash 脚本」，而要封装成带校验的工具。

## C. 台词实验（TTS 源 + ASR 判据）

| # | 坑 | 现象 | 对策 |
|---|---|---|---|
| 18 | GPT-SoVITS **v2 截断长句** | 4.9 s 的台词只合成出 2.5 s，后半句直接消失 | 换 **v3**（同一句给 7.1 s） |
| 19 | ★★ v3 返回 **int16 量级数组** | 峰值 22352，`soundfile` 按 float 写 PCM_16 → 硬削顶：rms 0.95、频谱平坦度 0.15（正常 0.01–0.05），削波谐波污染 HuBERT ⇒ 换声后 **CER 1.0** | 写盘前归一化（×0.9）。**「换声把人声搞崩了」先查输入电平，再怀疑模型** |
| 20 | TTS 需要自己的 venv | 借别的 env 会一路缺依赖（`ffmpeg-python` → `peft` → `jieba` → `pyopenjtalk`） | 用 TTS 项目自带的 venv |
| 21 | CosyVoice `instruct2` 把指令当台词念 | ASR 回读成「请只回答我的问题，**语速适中，句间自然停顿**」，CER 1.25 | 指令必须以 `You are a helpful assistant. ` 开头、`<|endofprompt|>` 结尾；补前缀后长句仍漏尾巴 ⇒ 改用 `cross_lingual` |

## D. 中文特有的测量陷阱

| # | 坑 | 现象 | 对策 |
|---|---|---|---|
| 22 | ★★ `pyin` 测声调假报警 | 声调轮廓 r=.44、RMSE 4 半音（等于换了调型），但 ASR 声调 CER = 0 | 换声后 `pyin` 半音 std 从 2.94 跳到 **6.92**（八度跳变），是**估计器**坏了。改用 `rmvpe` 后 r=.99。**两个判据打架先怀疑工具** |
| 23 | DTW 在短句上拉错曲线 | 1.2 s 浊音的句子 DTW 给 r=.64 | 时长比只差 1%，根本不需要弯曲 ⇒ 改**线性对齐**，稳定在 .98–.99 |
