# 模型清单格式（`.rvc-manifest.json`）

每个音色目录放一份 `model.pth` + 一份 `added_*.index`，再放一份 `.rvc-manifest.json`
把「这个模型是什么、怎么训的、实测多少」写清楚。`rvcx.voice list` 和
`tools/build_model_index.py` 都读它。

放在音色目录里（而不是集中在别处），因为清单跟着权重走——复制目录时不会掉。

---

## 推荐 schema（v3）

```json
{
  "format": "rvc-v2",
  "engine": "RVC-WebUI 2.3.260718",
  "engine_commit": "81eed5e",
  "voice": "角色名",
  "created": "2026-10-25",

  "model": {
    "file": "model.pth",
    "bytes": 57537548,
    "sha256_16": "19bb2bf3b9205283",
    "ceiling": "48k",
    "version": "v2",
    "if_f0": 1,
    "epochs": 120,
    "steps": 13440,
    "batch_size": 4
  },

  "index": {
    "file": "added_IVF1419_Flat_nprobe_1_xxx_v2.index",
    "sha256_16": "725e277426dc8bd4",
    "note": "只认 added_*，trained_* 是中间产物"
  },

  "train_data": {
    "files": 358,
    "minutes": 24.8,
    "slices": 445,
    "f0_method": "rmvpe",
    "notes": "filelist 含 2 条 mute 静音样本，否则气口会喷噪"
  },

  "recommended_infer": {
    "f0_method": "rmvpe",
    "index_rate": 0.75,
    "protect": 0.33,
    "pitch": 0
  },

  "measured": {
    "probe": "探针素材描述",
    "reference": "参考集描述（含留一法自测上限）",
    "ltas_r_src": 0.9512,
    "ltas_r_out": 0.9920,
    "delta_r": 0.0409,
    "f0_median_diff_hz": -3.9,
    "peak": 0.7833,
    "exact_zero_ratio": 0.0
  },

  "perf": {
    "gpu": "RTX 5060 Laptop 8G (sm_120)",
    "infer_15s_seconds": 5.35,
    "train_minutes_per_epoch": 1.09
  },

  "caveats": ["200 轮与 120 轮客观差异在噪声内", "LTAS 判方向可靠、判自然度不可靠"]
}
```

必填只有四项：`model.file`、`index.file`、`recommended_infer`、`voice`。
其余缺失时索引脚本填 `null`，**不猜**。

## 版本漂移：本机出现过三种 schema

真实使用中清单会进化。`tools/build_model_index.py` 的 `normalize()` 把三种拉成同一套字段：

| 版本 | 特征 | 实测数据在哪 | 轮次在哪 |
|---|---|---|---|
| **v1**（最早） | `model_version` / `epoch` / `global_step` / `dataset{source,files,slices_3_7s}` | `probe_metrics`（键名 `ltas_corr_output_vs_target`） | `epoch` |
| **v2** | `model{epochs,steps,...}` / `train_data` | `measured`（扁平） | `model.epochs` |
| **v3** | 同 v2，但实测分通道 | `measured.singing` / `measured.dialogue.tts_channel` | `model.epochs` |

### 归一化规则

```
版本   ← model_version | model.version | format 结尾 "v2"
轮次   ← epoch | model.epochs | 从目录名「步数(\d+)」推断
实测   ← measured.singing | measured(含 ltas_r_out) | probe_metrics
Δr     ← measured.delta_r | (ltas_r_out − ltas_r_src)
推理参 ← recommended_infer | 默认 {rmvpe, 0.75, 0.33, 0}
```

### 缺字段的兜底

若 `measured` 缺某个键（例如 v3 的 singing 里没有 `peak`），索引脚本会用
`models/measurements/grid.json` 里同轮次的网格测量**补空格**，已有值不覆盖，
并在 `source` 字段注明来源。这样索引表不会因为清单写得不全而出现大片 `—`。

## 为什么仓库不放权重

1. 单个 `added_*.index` 约 170 MB，超 GitHub 单文件 100 MiB 硬限制；
2. 音色模型是衍生作品，公开分发取决于训练数据与角色的授权，不属于代码许可证的覆盖范围。

所以 `models/` 下只放 `index.json`（含 sha256）、`INDEX.md`（人读）和
`measurements/`（原始测量数据）。拿到权重的人可以逐字节核对 sha256；
没拿到的人也知道该按什么参数自己训一个。

重新生成索引：

```bash
python tools/build_model_index.py                  # 扫 RVCX_MODELS
python tools/build_model_index.py --models D:/x    # 扫指定目录
```
